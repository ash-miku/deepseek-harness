# Agent Note: 批量归档未更新会话

Status: implemented

[English](2026-08-15-bulk-archive-inactive-sessions.md) | 中文

## 问题

侧边栏中大量已结束会话会让列表难以扫视。行内归档操作一次只清理一个会话，而删除 Workspace 会把会话移到未分组而不是减少列表，因此缺少低风险地清退大量积压会话的入口。

## 决策

Workspace 浏览器区头在视图选项和添加工作区旁增加归档图标。它打开一个支持 7、30、90、180 天阈值的对话框，并在提交前预览符合条件的数量。`selectInactiveSessions` 选择列表已就绪、非空白、非子代理且 `updatedAt` 早于截止时间、也不在注册表归档集合中的空闲会话。当前、运行中、待交互、空白、子代理和已归档会话会被排除。确认操作对每个候选调用现有且幂等的 `archiveSession` 动作，并在同一对话框内报告成功、部分失败和空结果。

## 考虑过的替代方案

**把阈值直接放进行菜单。** 行级操作无法高效覆盖积压，用户需要按会话重复操作。

**不预览直接归档。** 批量归档可逆，但预览让阈值语义更明确，也避免数量出乎意料。

**新增 Host 批量 RPC。** 现有归档动作已经幂等，Web 对象层也会安装完整归档集合；新增 RPC 会重复持久操作，却不会带来界面可见的收益。

## 后果

- 已结束会话可以通过一次操作从活动列表退出，同时保留日志和记账席位。
- 该动作只存在于浏览器：它组合现有 archiveSession 调用，因此 Host 的归档集合不变量与失败行为都不变。
- 宽屏与轨道状态都提供批量归档入口。

## 测试

单元测试覆盖阈值边界、列表就绪状态、缺失行和所有排除项。UI 测试覆盖预览数量、空状态、进行中提示、全部成功和部分失败。
